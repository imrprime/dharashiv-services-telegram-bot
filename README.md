# 🛠️ धाराशिव होम सर्व्हिसेस टेलिग्राम बॉट (Dharashiv Home Services Telegram Bot)

मराठी आणि इंग्रजी भाषेतील टेलिग्राम बॉट — धाराशिव शहर (उस्मानाबाद) आणि आजूबाजूच्या सर्व खेड्यांसाठी घरगुती सेवा व प्रत्यक्ष पाहणी/एस्टिमेट बुकिंग प्रणाली.

---

## 🌟 वैशिष्ट्ये (Key Features)

1. **द्विभाषिक संवाद (Bilingual Support):**
   - जेव्हा वापरकर्ता **"Hi"**, **"हॅलो"**, **"नमस्कार"** किंवा `/start` पाठवतो, तेव्हा बॉट आपोआप मराठीत आदरपूर्वक स्वागत करतो.
   - वापरकर्ता कधीही एका क्लिकवर **मराठी ⇄ English** भाषा बदलू शकतो.

2. **सर्व आवश्यक सेवांचा समावेश (Supported Services):**
   - ⚡ **इलेक्ट्रिशियन (Electrician):** वायरिंग, फॅन, गिझर, शॉर्ट सर्किट, स्वीच बोर्ड.
   - 🎨 **घर रंगकाम (Home Painting):** आतील/बाहेरील रंगकाम, वॉटरप्रूफिंग, पुट्टी.
   - 📡 **डिश टीव्ही दुरुस्ती (Dish TV Repair):** टाटा प्ले, एअरटेल, डिश टीव्ही सिग्नल सेटिंग व फिटिंग.
   - 🔧 **प्लंबिंग (Plumbing):** नळ लीकेज, पाण्याची टाकी फिटिंग, पाईपलाईन, सॅनिटरी काम.
   - ☀️ **सोलर सिस्टीम (Solar System Repair & Sell):** सोलर वॉटर हिटर, रूफटॉप सोलर पॅनेल बसवणे व दुरुस्ती.
   - ❄️ **फ्रिज व वॉशिंग मशीन (Fridge & Washing Machine):** कूलिंग समस्या, गॅस भरणे, मोटर रिपेअर.
   - 🧱 **लहान बांधकाम दुरुस्ती (Small Construction Repair):** टाईल्स, कट्टा बांधकाम, प्लास्टर दुरुस्ती.
   - 🌱 **लॉन व बागकाम (Lawn Making & Gardening):** नवीन लॉन तयार करणे, झाडे छाटणी, माती व खत.
   - 🛠️ **इतर सर्व प्रकारच्या सेवा (All Kind of Services):** सुतारकाम, आरओ, वेल्डिंग इ.

3. **धाराशिव परिसर केंद्रित (Dharashiv & Nearby Villages Focus):**
   - धाराशिव शहर, समर्थ नगर, शिवाजी नगर, नेहरू चौक, MIDC, तसेच **येडशी, तेर, ढोकी, बेंबळी, कळंब रोड, तुळजापूर नाका** आणि इतर सर्व ग्रामीण भागांसाठी विशेष पर्याय.

4. **सोपे व जलद बुकिंग (Seamless Visit Booking):**
   - नाव विचारणे
   - मोबाईल नंबर (बटणाद्वारे एक-क्लिकमध्ये "Share Contact" किंवा मॅन्युअल नंबर)
   - पत्ता / गाव निवडणे
   - कामाचे स्वरूप / समस्या
   - तंत्रज्ञाच्या प्रत्यक्ष व्हिजिटसाठी सोयीची वेळ (Visit for Estimation)
   - तात्काळ युनिक बुकिंग आयडी (उदा. `DH-261106-0001`) सह पुष्टीकरण संदेश.

5. **अ‍ॅडमिन / मालकांसाठी सुविधा (Admin & Business Management):**
   - **तात्काळ नोटिफिकेशन:** नवीन ग्राहक नोंदणी होताच मालक/तंत्रज्ञाला टेलिग्रामवर संपूर्ण माहितीसह अलर्ट येतो.
   - **थेट कॉल व स्टेटस बदलणे:** टेलिग्राम मेसेजमधूनच एका क्लिकवर *📞 संपर्क केला*, *📅 व्हिजिट ठरली*, *✅ काम पूर्ण झाले* असे स्टेटस बदलता येते.
   - **डेटाबेस:** सर्व लीड्स आपोआप SQLite (`leads.db`) मध्ये सुरक्षित राहतात.
   - **Excel / CSV एक्सपोर्ट:** `/export` कमांड देऊन सर्व ग्राहक माहिती एक्सेल/सीएसव्ही फाईल स्वरूपात डाऊनलोड करता येते.

## 🚀 सुरू कसे करावे (Setup Instructions)

### १. टेलिग्राम बॉट टोकन मिळवा
1. टेलिग्रामवर `@BotFather` शोधा.
2. `/newbot` पाठवा आणि सूचनांचे पालन करून बॉटचे नाव व युझरनेम द्या (उदा. `DharashivServicesBot`).
3. BotFather तुम्हाला एक **API Token** देईल (उदा. `7123456789:AAH...`).

### २. स्वतःचा Telegram Chat ID मिळवा (Admin Notifications साठी)
1. टेलिग्रामवर `@userinfobot` ला `/start` करा.
2. तो तुमचा संख्यात्मक **ID** देईल (उदा. `123456789`).

### ३. `.env` फाईल सेट करा
`/workspace/project/.env` उघडा आणि तुमचे टोकन व फोन नंबर प्रविष्ट करा:

```ini
BOT_TOKEN=7123456789:AAHxxxxxxxxxxxxxxxxxxxx
ADMIN_IDS=123456789
SUPPORT_PHONE=+91 98XXXXXXXX
SUPPORT_WHATSAPP=+91 98XXXXXXXX
```

### ४. बॉट चालू करा
सर्व डिपेंडन्सी स्थापित करून बॉट रन करा:

```bash
# डिपेंडन्सी स्थापित करा
pip install -r requirements.txt

# चाचणी चालवा
python3 test_system.py

# बॉट सुरू करा
python3 bot.py
```

बॉट २४×७ बॅकग्राउंडमध्ये चालू ठेवण्यासाठी `nohup` किंवा `systemd` वापरू शकता:
```bash
nohup python3 bot.py > bot.log 2>&1 &
```

## 🤖 उपलब्ध कमांड्स (Commands)

### ग्राहकांसाठी (For Customers):
| कमांड | वर्णन |
| :--- | :--- |
| `/start` किंवा `"Hi"` / `"नमस्कार"` | बॉट सुरू करणे, मराठीत स्वागत व सेवा निवडणे |
| `/services` | सर्व उपलब्ध सेवांची सविस्तर माहिती |
| `/myrequests` | आपल्या मागील नोंदी व सध्याचे स्टेटस तपासणे |
| `/language` | भाषा निवडणे (मराठी किंवा English) |
| `/contact` | धाराशिव कार्यालयाचा पत्ता, फोन व व्हॉट्सॲप नंबर |
| `/help` | मदत आणि सूचना |

### अ‍ॅडमिनसाठी (For Admin / Owners):
| कमांड | वर्णन |
| :--- | :--- |
| `/leads` | नुकत्याच आलेल्या १० सेवा विनंत्या पाहणे |
| `/lead <id>` | विशिष्ट ग्राहकाची संपूर्ण माहिती पाहणे |
| `/export` | सर्व ग्राहकांची एक्सेल/सीएसव्ही (CSV) फाईल टेलिग्रामवर मिळवणे |
